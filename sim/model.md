# Calibration Simulation Model (`Development` Environment Only)

> **IMPORTANT:** Every artifact, ledger CSV, and export generated by `sim/simulate.ts` is **SIMULATED** (`label=SIMULATED`) for pipeline validation, exposure attribution checks, and statistical calibration only. Simulated runs are **never** behavioral evidence and **must never** run against Production keys.

## Generative Model

- **Participant Skill:** $\theta \sim \operatorname{Beta}(4, 4)$ (symmetric prior centered at $0.50$).
- **Per-Attempt Solve Probability:**
  - Control arm: $p_{\text{control}} = \theta \cdot b_{\text{control}}$, where $b_{\text{control}} = 0.35$.
  - Counterexample arm: $p_{\text{counterexample}} = \theta \cdot b_{\text{counterexample}}$, where $b_{\text{counterexample}} = 0.35 \cdot (1 + \delta)$.
- **Give-Up Hazard:** $0.15$ per failed attempt, eligible **only** after 2 failed attempts on that challenge (matching the UI's `"Show solution"` lock).
- **Transfer Checkpoint (Challenge 3):** Solve probability per attempt $= \theta \cdot 0.50$, independent of arm (verifies that the transfer guardrail stays neutral).
- **Calibration Scenarios:** $\delta \in \{0, +0.3, -0.2\}$, seeds $\in \{1, 2, 3\}$, $N = 400$ users per scenario, fresh identity prefix `sim-s<delta>-<seed>-<n>`.

## Safety Guards

`sim/simulate.ts` enforces:

1. Refuses to execute if `FLAGSMITH_DEV_ENV_KEY` is empty (unless `--mock-local` dry calibration is explicitly requested).
2. Refuses to execute if `FLAGSMITH_DEV_ENV_KEY === FLAGSMITH_PROD_ENV_KEY`.
3. Refuses to execute if `VITE_APP_ENV === 'production'`.
4. Uses serial single-browser-process execution (`headless: true`, `channel: 'chrome'`) to keep laptop RAM safely below thresholds.
